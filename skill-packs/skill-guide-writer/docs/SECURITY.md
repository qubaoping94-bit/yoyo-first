# 安全边界

## 默认防护

- 不读取、回显或总结 Secret、Token、Cookie、API Key、密码、私钥和账号数据。
- 自动盘点跳过名称疑似包含敏感信息的文件。
- 从公开资料提取 URL 时移除 query string 和 fragment。
- 跳过 `.git`、`node_modules`、虚拟环境、构建目录和缓存。
- 不把 README 宣传语自动视为已确认能力。
- 不把底层工具的通用能力自动算作 Skill 自带能力。
- 不虚构官方仓库、画廊、演示、版本、价格、许可证或支持平台。

## 外部操作边界

编写使用说明不自动授权：

- 安装目标 Skill 或第三方依赖；
- 调用真实 AI Provider 或付费 API；
- 启动 OAuth；
- 部署、发布或切换生产流量；
- 执行飞书、IMA、邮件或其他外部平台写入。

这些操作只有在用户明确要求且满足对应安全条件时才能执行。

## 已知限制

- 文件名过滤只是降低泄露风险，不等于完整代码安全审计。
- URL 被提取不代表已经联网验证可访问。
- 第三方资料可能变化，文档需要记录核验日期并定期更新。
- 没有公开许可证时，不得推断可以商业使用或再分发。
- 自动盘点不能代替 Agent 对核心资料的完整阅读。

## 发布卫生

提交或分享生成的文档前，应再次检查：

- 私有绝对路径；
- 客户名称与内部项目名；
- 查询参数和临时下载地址；
- `.env`、日志、截图和调试输出；
- 未经授权的第三方素材或大段版权内容。
