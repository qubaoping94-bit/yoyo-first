# 标准工作流

## 路线 A：总结本机已安装 Skill

1. 根据名称定位真实安装目录。
2. 完整读取 `SKILL.md`。
3. 运行安全目录盘点。
4. 阅读直接相关的模板、参考、示例和脚本。
5. 生成中文 Markdown 并执行质量门禁。

适用于需要准确反映当前电脑真实安装版本的任务。

## 路线 B：总结 GitHub 或在线 Skill

1. 定位仓库中的 canonical `SKILL.md`。
2. 核验官方 README、release、演示、画廊、安装方式和许可证。
3. 区分仓库当前版本与本地安装版本。
4. 对易变信息记录核验日期。
5. 输出可独立阅读的说明文档。

## 路线 C：更新现有说明

1. 读取现有 Markdown。
2. 重新核验目标 Skill 当前资料。
3. 保留仍然正确的结构与内容。
4. 只更新有证据支持的过时信息。
5. 单独列出无法确认的内容。

## 路线 D：多个 Skill 统一文档化

1. 为每个 Skill 独立建立来源清单。
2. 每个 Skill 生成一份独立 Markdown。
3. 统一首屏、标题层级、调用示例和质量门禁。
4. 禁止跨 Skill 复用未经核验的能力描述。

## 默认输出顺序

1. 标题；
2. 可直接复制的最简调用；
3. 官方在线资源与仓库；
4. 定义和核心能力；
5. 场景、输入输出和路线；
6. 调用示例；
7. 工作流、安装和排错；
8. 限制、安全、版本与来源。
