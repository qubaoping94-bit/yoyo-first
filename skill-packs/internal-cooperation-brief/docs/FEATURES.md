# 能力

- 零散合作材料→内部汇报结构：需求、模式、策略、待决定事项。
- 商务蓝单栏、中文章节与括号序号、独立编号栏及续行对齐。
- 首要任务用行动语气；事实、意向、拟议、已成交状态不混写。
- 金额单位、尺寸和名称可配置防拆行与少量强调。
- 自包含HTML、规范JSON、微信高清单图、一页PDF及手机核验图。
- 导出拒绝覆盖，检查正文、图长、页数、360/390/430px溢出，阻断远程请求。
- Codex/WorkBuddy共享同一Skill，不需要专有MCP或模型API。

不包含自动抓取聊天记录、自动发送微信、云端发布、自动补造业务数据或对外客户宣传。真实微信压缩、WorkBuddy应用内自动选中、非Windows字体效果需要对应环境实际验收。
