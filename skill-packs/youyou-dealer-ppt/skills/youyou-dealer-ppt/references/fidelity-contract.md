# 21 页正式样例的可迁移视觉合同

这份合同来自 2026-09-27 正式交付包的 `source/index.html`、21 张逐页图及内容台账；只规定新稿的视觉与交互质量，不要求复制样例页数或历史文案。无需访问本机样例时，先用 `assets/approved-21-fixture.html` 查看可运行的无业务内容布局。

## 画布与结构

- 设计基准 1920×1080、16:9；允许 1280×720 等比例实现，但**所有字号、边距、线宽、卡片尺寸必须按 2/3 同步换算**，验收先换算回 1920 设计单位或比较归一化屏幕比例。禁止把 `28px` 原样用于不同画布后再声称等效。
- 正式样例使用暖米白 `#f4f1e8`、近黑 `#171815`、红 `#e63b2e`、辅助灰 `#686a64`；约 96px 网格、左侧约 28px 红竖条。顶部红通栏**不是**该样例的识别骨架。
- 1920 基准：页面左右安全边距约 66px，页眉约 66px 高且有底线；主体自约 y=126 至页脚安全区；页脚细线、来源/边界与页码贯穿全稿。封面、章节、内容页可变化，但视觉身份连续。
- 标题根据内容采用约 64–92px；封面或少量短语可更大（样例封面主标题约 138px）。正文样例基线约 27–36px，卡片标题约 34px；来源页脚约 16px。长文先拆页或改结构，不靠压成细小灰字。灰色正文与背景须维持投影可读性。
- 用大卡片、对比、流程、公式、网格、红底结论交替承载信息。少量聚焦留白可保留，但连续页面不得让正文只占上半区、下半部空荡；不要靠大数字、细竖线或装饰符填空。
- 参考页型：封面双栏、八项能力 4×2 信息卡、密度公式+四宫格、五大平权总览、经销商六步流程。按新稿信息选择页型，不强迫每页配图。图像需要时应无重复、无缺图，完整展示关键文字/产品；不加多余厚框，不裁掉重要信息。

## 内容与证据

- 保留用户本次提供的中心内容，但不要将样例旧文案/旧页数当作事实真源。每页建立标题—核心命题—必要证据—边界—备注的对应关系。标题和副标题的粗细、断行与红色强调服务于层级，不做全字重同级。
- 八零已是当前口径；旧字符串“七零”出现时应报错（引用历史资料作为对比时需明确标注）。五大平权在不同资料出现两套名称：样例为安全/功能/品质/空间/环保，本次 13 页稿为技术/功能/豪华/生活/环保；**不可由模型自行认定哪套更新**。没有权利人批准来源时，列为阻断项，不做正式对外稿。
- 甲醛、A级不燃、全系标配、成本、价格、使用年限、释放周期等必须有具体型号/报告/政策/检出限或项目证据。没有证据的确定表述不得列入“可以这样说”。板材性能不外推到整门；无机胶凝结构不等于所有下游工艺无胶。

## 现场与导出

- HTML 默认支持方向键、PageUp/PageDown、滚轮一格一页与 `P` 备注；备注内部滚动不翻页；减少动效时直接显示终帧。演讲窗口应有明确退出方式和离线备份。
- 生成 HTML/PDF/PPTX 后，按同一页码、同一比例分别渲染截图，比较标题、字体、裁切、图片与备注状态；仅页数一致不足以证明格式一致。
- 逐页 100% 目检 + 50% 可读性检查 + 代表页同视口并排样例对照。先冻结封面、密集信息、对比/流程、结论四类代表页；视觉方向不符时不扩散全稿。新稿未获用户认可前称候选，不称“视觉通过”。
