# 黑红数据公报动效系统

## 必须具备

- 翻页反馈：新页面整体轻微淡入，约 260–340ms。
- 阅读顺序：页眉、栏目标签、标题、主体卡片/表格、结论、页脚依次进入。
- 单个元素：从下方约 24–32px 上移并淡入，约 480–560ms。
- 错峰间隔：每组 55–75ms；超过10项后不再继续增加总延迟。
- 缓动：`cubic-bezier(.2,.72,.2,1)` 左右，避免弹跳和花哨旋转。
- 输入控制：默认同时支持滚轮上下翻页、左右方向键、PageUp/PageDown和空格前进。
- 滚轮控制：下滚只前进一页，上滚只返回一页；设置最小增量阈值与350–500ms节流，防止一次滚动连续跳页。
- 备注面板：鼠标位于已打开的演讲者备注面板内时，滚轮只滚动备注，不切换幻灯片。

## 约束

- 只动画 `transform` 和 `opacity`，不动画宽高、位置流或网格尺寸。
- 每次翻页取消该页旧动画后重新播放，避免快速翻页残留半透明状态。
- 不使用循环动画、粒子、视差或滚动劫持。
- `prefers-reduced-motion: reduce` 时跳过动画，内容直接完整显示。
- 打印与导出模式强制 `visibility:visible; opacity:1; transform:none`。
- 导出PPTX时使用减少动态模式或专用导出样式，不能截到动画中间帧。

## 验收

- 连续快速前后翻页，文字始终能恢复到完整可见状态。
- 进入页面后不超过约1.2秒即可读到全部主体内容。
- PDF/PPTX与HTML动画最终帧的布局一致。
- 自动测试必须覆盖：第1页下滚到第2页、第2页上滚回第1页、备注面板内滚动页码不变。
