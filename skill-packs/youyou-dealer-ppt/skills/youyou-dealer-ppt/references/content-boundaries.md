# 优优门用无机板内容边界

- 优优供应门用无机板基材；成门由合作门厂共同设计、制造和交付。
- D8、D9、D5、D2属于候选、专项或联合验证方向，不自动等于现售 SKU。
- D2是门套线复合无机薄层，不是2mm独立承力门套。
- 板材表现不等于整门性能；环保、隔声、耐火、耐久按层级分别举证。
- 八零体系按以下顺序核对：零木质材料、零胶水体系、零石棉成分、零玻璃纤维、零塑料成分、零化学阻燃剂、零防水剂、零防霉剂。样例中的旧 ID `seven-zero` 只是历史标识，绝不把它当成七零事实。
- 零胶水体系仅指板材本体的无机胶凝成板路线，不等于没有胶凝材料，也不外推到饰面、复合、封边、安装或完整门墙柜。无机矿物不直接等同于玄武岩；不得说“纯玄武岩板”。
- 环保按材料、配方、成品、空间四层讲；甲醛等检测措辞必须逐字核对具体报告、型号与检出限。不要说全屋绝对零甲醛、100%无害、医疗级。
- 板材 A 级不燃不等于整门获得防火门资质；隔声也应回到整门结构、密封、安装和检测。不把隔声说成吸音，不承诺绝对隔音。
- 五大平权（安全、功能、品质、空间、环保）是价值框架，不承诺所有产品同价同配、无条件标配。
- 若项目需沿用已核准的 D5 50mm 几何演示，使用 `5+40+5`，与 `12+26+12` 比较内部空间 `26→40`（+14mm，约 53.8% 几何变化）；先确认型号与口径。旧 45mm / `5+35+5` 示例已过时，不能当当前默认值；几何变化不等于性能同比提高。
- 密度降低不自动证明性能不变；整门重量与成本必须回到完整 BOM。
- 不承诺未经确认的独家权、补贴、利润、销量、回本周期或认证结果。
- 正式品牌语：`无机门，让门的每一毫米都体现最大的使用价值！`
