# 优优演讲系统视觉规范（以 2026-09-27 正式交付样例为主）

## 色彩与画布

- 16:9 固定舞台，以 1920×1080 为设计单位；1280×720 等比例实现时，所有内部尺寸按 2/3 同步换算，并以归一化屏幕比例验收。
- 背景为暖米白 `#F4F1E8` 左右，细灰网格贯穿全稿。
- 主文字近黑 `#171815`，强调红 `#E63B2E`，辅助灰 `#686A64`。
- 保留**左侧红识别条**（1920 基准约 28px）、约 96px 细网格、页眉底线与页脚细线；顶部红通栏不是当前样例。避免圆角、渐变、玻璃拟态和装饰图标堆叠。
- 该配色来自用户指定的 21 页 EXE 样例，不是此前网页分类培训站或深绿金色稿。不要混淆不同载体。

## 字号与密度

- 1920 设计单位下，主体标题常见 64–92px；封面短主标题可至约 138px；内容允许时优先单行。
- 卡片标题约 34–45px；讲述正文约 27–36px，短句和稀疏页面优先 30–36px；来源、页脚和真正注释可更小。不同画布比较须先换算，不能机械计数原始 `font-size`。
- 大数字通常 90–160px，不得压过结论与正文。
- 先扩大容器、重排信息组，再增加字号；不要用巨大数字机械填空。
- 页面应覆盖主要有效画布，保留结构间距而不是空洞。
- 主体容器需占满标题下方至页脚安全区之间的主要高度；信息组垂直居中。连续大块空白不得超过主体区约四分之一，除非它承担明确的对比、聚焦或转场作用。
- 在50%演示预览中仍应能辨认标题和主要正文；若正文需要靠放大窗口才能读清，视为失败。
- 刻意留白只用于焦点、对比或转场。若第 2、3、11 页那样连续出现主体上挤、下方大片无信息区，应重构内容组而非仅调字号或添加细线；代表页先与 fixture/样例同视口并排。

## 组件规则

- 双栏：信息量平衡，短说明垂直居中。
- 卡片：编号、标题、说明作为一组垂直居中。
- 长文卡片只把短标题加粗；解释正文用常规字重和辅助灰，保持 27–36px 可读字号。源文案以 `｜` 分开标题/解释时，渲染层可分级显示，但不得删改文字。三栏材料说明优先用开放分栏与细分隔线；不要每栏都加厚底板、红顶线或把整段说明加粗。四宫格可保留浅灰底板，但需有明显的标题—解释层级。
- 表格：表头紧凑，正文行获得主要高度；正文居中或按数据类型对齐。
- 流程：严格等宽 `minmax(0,1fr)`，编号与说明居中成组。
- 数据页：数字与单位 `white-space:nowrap`，flex 对齐并留 20px 以上安全间距。
- 结论和品牌语：使用红底白字的大块核心视觉，不贴近页脚。
- 页眉：英文栏目名与中文标签；页脚：一句边界或结论加自动页码。
- 页面有图时先匹配图像比例与版式，完整展示关键信息；图片已有留白/文字时避免再套一层厚框。重复图、缺图和无意义缩略图必须全稿扫描。不得为了“满填”裁掉产品、标注或文字。

同一视觉系统内轮换双栏、2×2 卡片、三/四列卡片、表格、流程、公式和结论页，避免每页同构。

不要把“多列”误读成细竖线切成三到五份：样例更强调有足够高度和内边距的大信息组。若五列使正文变成细小段落，拆成总览+分讲页或改为 2×2/4×2 结构。
