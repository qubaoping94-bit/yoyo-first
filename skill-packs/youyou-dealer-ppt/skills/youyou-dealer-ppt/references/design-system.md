# 优优演讲系统视觉规范（以 2026-09-27 正式交付样例为主）

## 色彩与画布

- 16:9 固定舞台，推荐 1920×1080。
- 背景为暖米白 `#F4F1E8` 左右，细灰网格贯穿全稿。
- 主文字近黑 `#171815`，强调红 `#E63B2E`，辅助灰 `#686A64`。
- 保留窄红识别条；避免圆角、渐变、玻璃拟态和装饰图标堆叠。
- 该配色来自用户指定的 21 页 EXE 样例，不是此前网页分类培训站或深绿金色稿。不要混淆不同载体。

## 字号与密度

- 主标题 64–92px；内容允许时优先单行。
- 卡片标题 34–45px；正文默认 28–36px，短句和稀疏页面优先 30–36px；只有来源、页脚和注释可低于24px。
- 大数字通常 90–160px，不得压过结论与正文。
- 先扩大容器、重排信息组，再增加字号；不要用巨大数字机械填空。
- 页面应覆盖主要有效画布，保留结构间距而不是空洞。
- 主体容器需占满标题下方至页脚安全区之间的主要高度；信息组垂直居中。连续大块空白不得超过主体区约四分之一，除非它承担明确的对比、聚焦或转场作用。
- 在50%演示预览中仍应能辨认标题和主要正文；若正文需要靠放大窗口才能读清，视为失败。

## 组件规则

- 双栏：信息量平衡，短说明垂直居中。
- 卡片：编号、标题、说明作为一组垂直居中。
- 表格：表头紧凑，正文行获得主要高度；正文居中或按数据类型对齐。
- 流程：严格等宽 `minmax(0,1fr)`，编号与说明居中成组。
- 数据页：数字与单位 `white-space:nowrap`，flex 对齐并留 20px 以上安全间距。
- 结论和品牌语：使用红底白字的大块核心视觉，不贴近页脚。
- 页眉：英文栏目名与中文标签；页脚：一句边界或结论加自动页码。
- 页面有图时先匹配图像比例与版式，完整展示关键信息；图片已有留白/文字时避免再套一层厚框。重复图、缺图和无意义缩略图必须全稿扫描。不得为了“满填”裁掉产品、标注或文字。

同一视觉系统内轮换双栏、2×2 卡片、三/四列卡片、表格、流程、公式和结论页，避免每页同构。
