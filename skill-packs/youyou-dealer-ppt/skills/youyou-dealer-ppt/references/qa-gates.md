# 交付验收门禁

## 逐页视觉检查

- 标题、正文、数字、单位没有堆叠或裁切。
- 内容没有只挤在顶部；卡片内部没有大片无意义空白。
- 同类信息字号、对齐和间距一致。
- 页脚与正文保留清楚的安全区。
- 表格文字可在演讲距离阅读。
- 品牌语和行动结论位置显著。
- 记录每页最小正文计算字号；正文小于28px时必须有明确的页脚/注释豁免理由。
- 检查主体内容包围盒与有效内容区：无设计理由时，主体区上下连续空白不得超过有效高度约25%。
- 在50%预览下检查主要正文可辨认性；不能只查看100%截图或依赖浏览器溢出结果。
- 将封面、最密集信息页、对比/流程页、结论页与 `assets/approved-21-fixture.html` 和可用的 21 页真实样例做同视口并排对照；颜色相同但视觉骨架、密度或字重不同，判方向未通过。
- 任一页面触发小字/低密度返工时，对同类型页面执行全稿连带扫描并留下截图证据。

## 结构检查

- 所有页有唯一稳定 `data-slide-id`。
- 插页后原 ID、页面专属 CSS、动态注入与演讲备注仍对应正确页面。
- HTML、PDF、PPTX 页数、标题序列、页码和备注数一致。
- 自包含 HTML 不依赖外部 CSS、JS 或网络字体。
- 静态预检运行 `python scripts/audit-fidelity.py`；需在本包 fixture 上通过、在已知反例上捕获结构/旧口径等问题。脚本为低成本阻断器，不是视觉相似度证明。
- 动态HTML必须同时具备滚轮和键盘翻页；滚轮一次只移动一页，并保留备注面板内部滚动。

## 遮挡检查

普通矩形相交检测不足以发现层叠覆盖。对绝对定位底栏、浮层、演讲面板和动态组件：

1. 取必要文本矩形的左上、中心、右下采样点。
2. 用 `document.elementFromPoint()` 检查顶层命中是否仍属于原元素。
3. 三个点必须全部命中自身；不可隐藏或删除文字避测。

## 导出检查

- 先打开演讲面板采集备注，再关闭面板，之后才截图并生成 PPTX。
- 打印媒体隐藏按钮、热点、编辑提示和演讲者视图。
- 导出后重新渲染，不复用旧截图。
- 记录 HTML/PDF/PPTX SHA-256；保持 `NOT_APPROVED_BASELINE`，直到用户批准。
- 明确 PPTX 是视觉保真图片型还是可编辑型；不得把图片型文件描述为可编辑文本稿。
- 在交付电脑可用时，分别用 PowerPoint 与 WPS 打开检查页数、比例、字体和备注。
- 同一页分别从 HTML、PDF、PPTX 生成相同比例截图，检查位置、颜色、字重、断行和图片；只有页数/备注数一致不算三格式一致。
- 甲醛、A级不燃、八零、五大平权、全系标配、价格与年限等建立逐项来源台账。不同版本的五项名称未确认时报告 `CONTENT_VERSION_HOLD`，不得作为正式对外稿。
