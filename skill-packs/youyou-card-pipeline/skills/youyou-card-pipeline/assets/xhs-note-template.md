# 配套文案 · 主题标题

> 面向目标受众。口吻依据用户提供的作者与原文确定。正文严格≤1000字符。

### 推荐标题

1. 金句式标题
2. 疑问式标题
3. 比喻式标题
4. 内容概括标题
5. 使用场景标题

### 正文内容

钩子：用一个具体问题或现象切入。

现象或误区：讲清读者为什么会困惑。

来路或对照：依据原文解释观点从何而来。

使用端：保留读者实际关心的场景。

合作商或创作者：说明文章提供的实际价值。

收尾：总结核心判断；需要随正文带出的适用边界在这里保留。

### 推荐标签

#主题标签 #品类标签 #场景标签 #受众标签 #内容标签 #相关话题

### 爆款来源

写明真实原文和采用的资料；没有传播数据时不宣称已经成为爆款。

### 合规口径

写明与本文有关的性能、环保、供货或合作边界，不复制缺少现行证据的认证和检测结论。
