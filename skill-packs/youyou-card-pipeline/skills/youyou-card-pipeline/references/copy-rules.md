# 小红书配文规范（xhs-note.md）

配文是完整任务的必交付产物。默认“配图”“八卡”“图文”请求都包含配文；用户明确“只做图”时才省略，并在交付记录说明范围。只要求配文时，不强制渲染图片。

## 1. 输入与作者口吻

完整读取原文、用户补充、受众、必须保留/删除的内容。与八卡共同使用同一篇原文，不从模板补写卖点。

- 优优系列有用户确认的Mike作者身份时，保留原文第一人称和开场：“我是 Mike，优优智构 AI OS Founder & CEO｜优优新材&优优无机板 CSO。”身份有变化时使用用户提供的现行版本。
- 没有作者身份依据，不冒用Mike或职务；沿用文章已确认作者语气或中性叙述。
- 优优系列语气口语、直接、有材料逻辑；不堆术语、不做无依据的情绪煽动。
- 材料主体写全称“木质板材”“优优无机板”。防潮相关措辞遵循当前正式资料；不得擅自变成“绝对防水”。

## 2. 固定五个栏目

依次为 `### 推荐标题` → `### 正文内容` → `### 推荐标签` → `### 爆款来源` → `### 合规口径`，各栏目只出现一次。首屏标明主题、受众和口吻。

| 栏目 | 完整要求 |
|---|---|
| 推荐标题 | 5个不同标题，以1.至5.编号；至少包含金句式、疑问式、比喻式各一个。忠于原文，不制造已证实的销量/热度暗示 |
| 正文内容 | 6–8个自然段，段间空行，不用小标题、编号或项目列表；去空白后含标点≤1000字符 |
| 推荐标签 | 6–8个不重复且相关的标签；优优主题时可含#优优无机板、系列与本篇关键词，不塞无关热点 |
| 爆款来源 | 写真实原文、相关系列与已使用资料；原版栏目名不等于传播成绩，没有数据时不得写“已爆款” |
| 合规口径 | 保留与本文相关的来源、性能/环保/合作边界；无对应内容无需机械添加产品条款 |

模板见 `assets/xhs-note-template.md`，可运行示例见 `assets/note.example.json`。

## 3. 正文怎样写

优优文章默认骨架：**钩子 → 现象/误区 → 来路/对照 → 零售端 → 经销商/合作商 → 结构能力 → 收尾金句**。一般创作文章可改为对应使用端/创作者价值，不能强行补原文没有的合作内容。七个内容点可合并为6段或展开到8段。

配文负责连贯解释，不逐张抄卡片文字。保留核心钩子、主要论证、关键金句及与结论直接相关的适用边界；压缩重复过渡和次要举例。1000字符约束只用于小红书配文，不用于用户另外要求保留的完整文章或网页正文。

与图卡保持同一事实、数据、观点和删改要求。图文一方修改后，两方同步检查；图片上的对比不能在配文里换成另一种结论。

## 4. 生成与验证

由Agent先写完整 `note.json`，字段为 topic、audience、voice、titles（5项）、paragraphs（6–8项）、tags（6–8项，带#）、source、boundary。每项字符串为单行，自然段按数组分隔。脚本只组织已经写好的文字，不负责文章理解或自动创作。

```text
python scripts/build_note.py --input <note.json> --output <输出目录>
python scripts/validate_note.py <输出目录/xhs-note.md>
python scripts/count_body_chars.py <输出目录/xhs-note.md>
python scripts/validate_delivery.py <输出目录>
```

生成 `xhs-note.md`（5标题、正文、标签、来源、合规）、`小红书发布文案.txt`（默认第1标题+正文+标签）、`note.json` 和 `note-validation.json`。来源/编辑合规栏目不直接塞进发布文案；正文需要带的具体适用边界必须事先写入正文，不能仅藏在合规栏目。

完整图文交付再跑 validate_delivery，缺配文就失败。只做配文时加 `--mode copy-only`。用户明确只做图片时不运行图文齐套门禁，不得宣称“完整图文交付”。

正文计数只统计正文内容至推荐标签之间，去全部空白、保留标点，上限1000不可提高。超限时先删重复、合并过渡、精简次要例子，不能删掉必要边界。结构校验检查栏目顺序、数量、段落、标签、字数；标题风格、观点准确性、图文一致性、身份与来源真实性需人工/Agent审阅。

## 5. 内容与合规

不贬低旧路线/同行，不编造检测数据、认证、价格或客户故事，不承诺收益或经营结果。性能数据以当前官方报告与产品规格为准，写明适用范围；环保措辞依据已核验现行资料，不机械复制旧版“天然不含甲醛/CMA/UL金级”等具体结论。无证据时不写“第一/唯一/永远/绝对”等承诺。

按优优原文，可写“性能与环保相关表述，以优优官方检测报告、产品规格与技术资料为准；具体合作与供货条件以双方签署的正式协议条款为准，本文不构成任何经营结果承诺”。此为边界句，不证明正文中无依据的性能主张。

用户要求删除的模块不得从模板恢复；资料不足在来源/合规记录中说明，正文不写成确定事实。产出文案不等于发布到小红书，公开上传另需授权。以上为Skill内部规则，不代替平台实时发布规范。
