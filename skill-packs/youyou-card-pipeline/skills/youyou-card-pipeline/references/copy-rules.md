# 配文与内容规则

配文文件命名 xhs-note.md，使用以下标题结构：

```markdown
### 推荐标题
与文章内容一致的标题
### 正文内容
以具体问题开篇，展开主要观点，再自然收束。
### 推荐标签
#相关主题
### 来源说明
列明用户提供的文章或已核验资料。
### 内容边界
列明尚缺依据的性能、认证或数字，不将其写成确定事实。
```

正文计数：只计正文内容与推荐标签之间的字符，去掉全部空白，标点计入；上限1000。运行 scripts/count_body_chars.py，退出0通过、1超限、2输入格式错误。标签不计入此脚本的正文限额；平台自身发布规则仍需发布时核验。

沿用原文的受众、作者语气和用户指定文案。没有身份依据，不冒用作者职务。不补造检测等级、认证、价格、收益、环保结论或竞品定性；不贬低同行。不把示例当成产品证据。含性能数据时写明来源和适用范围。用户删掉的模块不得从旧母本恢复。公开发布另需授权。
