# 「优优无机板公众号文章一条龙」Skill 使用说明书

> 版本 v1.0 ｜ 技能名：`youyou-wechat-article-pipeline` ｜ 适用：WorkBuddy
> 一条命令跑完整篇公众号文章：选题 → 开头钩子分析 → 创作 → 去 AI 味 → 排版 → 配图 → 校验 → 推微信草稿箱。

---

## 一、这是什么

这是一套已在线上跑通 **8 篇文章**（A级不燃 / 无机矿物 / 玄武岩纤维 / 无机胶凝 / 环保 / 低异味 / 防潮耐水 / 抗菌防霉）的公众号生产流水线，固化了：

- **固定的创作角度**：Mike 第一人称 + 5 编号小节（01 误区 / 02 材料逻辑 / 03 零售话术 / 04 经销商话术 / 05 结构能力升华）
- **固定的开头套路**：融合版开头 9 步 + 「开头五项分析」钩子工序（读者/痛点/反常识/数字/好奇钩）
- **固定的排版**：Quiet Paper 工业风（配色写死、编号圆圈、深色收口框、合规边界框、固定页脚），正文全内联样式、微信编辑器即粘即用
- **固定的收尾**：写在最后 + 合规表达边界 + 作者卡/往期文章/喜欢作者页脚
- **固定的质量闸**：8 项校验清单全 PASS 才交付

**人工只做 4 类事**：确认选题、提供海报、审核措辞、下令推送。其余全自动。

## 二、一键安装

### 方式 A：文件夹安装（推荐）
1. 把整个 `youyou-wechat-article-pipeline` 文件夹（含 SKILL.md）复制到：
   - Windows：`C:\Users\<你的用户名>\.workbuddy\skills\youyou-wechat-article-pipeline\`
   - macOS：`~/.workbuddy/skills/youyou-wechat-article-pipeline/`
2. 重启 WorkBuddy 会话（新开对话）即生效。

### 方式 B：对话安装
把本说明书的 SKILL.md 原文发给 WorkBuddy，说：
> 「请把这段内容保存为我的用户级技能，路径 ~/.workbuddy/skills/youyou-wechat-article-pipeline/SKILL.md」

### 安装验证
新对话里说：**「写优优无机板公众号文章」** —— 若 AI 开始检索 IMA 知识库并列选题清单，即安装成功。

## 三、前置依赖（跑通全流程需要配齐的 7 件套）

| # | 依赖 | 说明 | 缺了会怎样 |
|---|---|---|---|
| 1 | **WorkBuddy** | 本 skill 的运行环境 | 无法使用 |
| 2 | **ima-mcp 连接器** | IMA 知识库 MCP（知识卡是文章唯一事实来源） | 选题与事实检索不可用，可改为用户提供资料 |
| 3 | **写作规则文件** `MEMORY.md` | 放在 `<WORKBUDDY_ROOT>/.workbuddy/memory/MEMORY.md`（含 Mike 身份、开头 9 步、排版配色、合规机制；路径不同的话设置 `WORKBUDDY_ROOT`） | AI 不知道固定套路，会自由发挥 |
| 4 | **build 脚本模板** | `<WORKBUDDY_ROOT>/wechat-draft/_build_youyou_*.py`（Quiet Paper 排版脚本，随第一篇文章一起分发） | 无法生成微信安全 HTML |
| 5 | **系统 Python 3.12 + Pillow** | build 用（受管 3.13 无 PIL 时需指定系统解释器路径） | 图片压缩/排版失败 |
| 6 | **wechat-publisher skill + 公众号凭证** | `scripts/publish.ts` + `.env`（AppID/AppSecret）；公众号后台 IP 白名单需加入运行机出口 IP | 无法推草稿箱（其余步骤不受影响） |
| 7 | **Node.js（npx tsx）** | 跑 publish.ts | 推送失败 |

> 只想先试用「写文章 + 排版预览」，配 1-5 即可；推送（6-7）可后配。

## 四、怎么用（标准对话流）

| 步骤 | 你说 | AI 做 | 你做 |
|---|---|---|---|
| ① 选题 | 「写优优无机板公众号文章」 | 检索 IMA「02｜可用知识」列待写主题 | 👤 指定主题（可截图画红线） |
| ② 钩子分析 | （自动） | 五项分析：读者/痛点/反常识/数字/好奇钩 | — |
| ③ 创作 | （自动） | Mike 第一人称初稿，5 编号小节 | — |
| ④ 去 AI 味 | （自动） | 活人化重写，事实与合规边界不动 | — |
| ⑤ 排版 | （自动） | 复制 build 模板改 5 处，生成手机外壳预览 | — |
| ⑥ 配图 | 粘贴海报图 | 像素特征校验映射→压缩嵌入→**把海报信息织进正文**→图注用海报原话 | 👤 给图；可红圈截图指定插图位置 |
| ⑦ 校验预览 | （自动） | 8 项校验 + 打开预览 | 👤 审核措辞（多轮微调，改一处 rebuild 一次） |
| ⑧ 推送 | 「推到草稿箱」 | 上传图+封面→创建草稿，返回 media_id | 👤 确认推送；删旧版草稿、改摘要 |
| ⑨ 发布 | — | — | 👤 微信编辑器手动插原生关注/赞赏组件，手动群发 |

**常用指令**：
- 「材料体系系列下一篇」—— 按系列节奏自动选下一篇
- 「推到草稿箱」—— 推送当前定稿

- 「做成小红书八卡」—— 可选扩展（需 guizang-social-card-skill）

## 五、常见问题（FAQ）

**Q1：推送报 40164 invalid ip？**
公众号后台 → 设置与开发 → 安全中心 → IP 白名单，加入报错里显示的出口 IP（IP 会随环境变化，非一劳永逸）。

**Q2：推送成功但草稿箱有多版？**
重推=新建草稿（不是更新）。删旧版即可；推前确认最新修改已 rebuild。

**Q3：AI 读不了我发的海报图？**
部分环境图片读取受限。本 skill 已内置应对：按文件名语义 + IMA 知识卡推断内容 + PIL 像素特征（明暗/色调）校验文件顺序，不影响配图准确性。

**Q4：草稿能直接群发吗？**
个人未认证订阅号 freepublish 接口被封，只能：草稿箱 → 手机预览 → 手动点群发。关注/赞赏请在编辑器里插原生组件。

**Q5：文章里的检测数据可以编吗？**
不可以。skill 强制：事实一律来自 IMA 知识卡，无数据就用结构数字（七零配方/5mm/2mm），对外表述以官方检测报告为准。

**Q6：换主题（非材料体系）能用吗？**
可以。套路（开头 9 步/5 小节/排版/页脚）通用，只需替换主题词、标题卡、合规边界条目。
