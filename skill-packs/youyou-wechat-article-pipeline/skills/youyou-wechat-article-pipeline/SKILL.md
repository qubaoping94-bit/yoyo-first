# 优优无机板公众号文章一条龙（youyou-wechat-article-pipeline）

## 本机路径配置
- `WORKBUDDY_ROOT`：文章与素材工作目录，例如 `<你的工作目录>`。
- `WORKBUDDY_HOME`：WorkBuddy 用户目录，通常为 `~/.workbuddy`。
- `PYTHON_312`：Python 3.12 解释器；未配置时使用 `python`。

## 何时用这个 Skill
用户说：写优优无机板公众号文章 / 材料体系系列下一篇 / 公众号文章一条龙 / 接着创作 XXX 主题 / 推到草稿箱（优优系列文章）。
覆盖全流程：选题 → 开头五项分析 → 创作 → **去 AI 味** → build 排版 → 配图 → 校验 → 推微信草稿箱。

## 单一事实来源（必读，不得在本 skill 内复制后偏离）
- **写作与排版强制规则**：`<WORKBUDDY_ROOT>/.workbuddy/memory/MEMORY.md`
  （Mike 第一人称、融合版开头 9 步、标题范式、5 编号小节、Quiet Paper 配色写死、布局顺序、合规边界机制、固定页脚、3 条写作红线、8 项校验清单）。每次创作前先读它，以它为准。
- **系列进度与最新决策**：`<WORKBUDDY_ROOT>/.workbuddy/memory/` 最新日期日志。

## 流程总览（👤 = 人工干预点，其余全自动）

### Step 1 选题 👤
1. 用 ima-mcp 检索「02｜可用知识」（kb_id=7483171998288016），列出系列待写主题清单给用户。
2. 👤 用户确认选题（常见形式：截图 IMA 表格画红线 / 口头指定主题）。
3. 取该主题知识卡完整内容（search_knowledge → fetch_media_content），作为**唯一事实来源**；搜索结果过大时落盘到 tool-results 再读。
4. **通道规则**：IMA OpenAPI 已被封（错误码 200005 quota-blocked），一律走 **ima-mcp**；遇 429 限流稍候重试即可。

### Step 2 开头五项分析（固定钩子工序，写初稿前做）
对选定主题按 5 问分析，结论直接喂给开头写作：
1. 读者是谁（深层=经销商/门店/板材厂，表层=南方潮湿地区业主）；
2. 读者现在最痛的点（找一个具象场景句）；
3. 内容里最反常识的观点（挖 1-3 条，最强的前置进金句）；
4. 最具体的数字/结果（没有硬数据就用结构数字：十个里九个 / 七零配方 / 5mm/2mm；**不得编造检测数据**）；
5. 哪句话最容易制造好奇心（把正文金句的张力拆一半到开头）。

### Step 3 创作
- 严格按 MEMORY.md：标题范式 `优优无机板：核心主题+比喻副标题`；融合版开头 9 步（元素不可缺，可微调）；5 编号小节 **01 先看一个误区 / 02 XX 逻辑 / 03 零售端怎么讲 / 04 经销商怎么讲 / 05 说到底是"结构能力"**；`## 写在最后` + `## 关于作者` 收尾。
- 3 条写作红线自查：不攻击消费者；不误构对手话术（用真实口径）；优优定位归材料体系（不归后期处理）。
- 融入系列固有逻辑：外添加会失效 vs 底座更换性能永久；胶水/添加剂也是外添加。
- 产物：`<WORKBUDDY_ROOT>/wechat-draft/youyou-<slug>.md`。slug=主题拼音（如 `youyou-kangjun-fangmei`）；frontmatter 含 title 与 **cover 场景句**（如 `cover: 回南天打开衣柜，最怕那股霉味`）， cover 句要具象、有画面。

### Step 4 去 AI 味（固定工序，初稿完成后必过，不得跳过）
对整篇初稿做一轮"活人化"重写（可加载 `humanizer-zh-moli` skill 辅助审校），铁律：**事实、数字、合规边界一条不动，只动表达**。
- **删结构腔**：不用"首先/其次/最后""总而言之""值得注意的是"；系列固定的 5 编号小节结构保留（那是刻意的），但小节内部的"三点式罗列腔"要拆。
- **加粗克制**：加粗只留给金句和关键判断，一段最多一处；不整句整段加粗当"重点"。
- **过渡口语化**：用"这话单看没错""再往深里看""说白了""卖板的人都知道"这类活人过渡，替代书面连接词。
- **不喊口号收束**：结尾不写"选择XX就是选择XX""让我们一起…"；收口落在具体判断上（系列固定收口框除外）。
- **句子节奏**：长短句交替，允许口语破句；连续三句以上等长就是 AI 味信号，拆掉重写。
- **红线联动**：去 AI 味过程中顺手复查 3 条写作红线（不攻击消费者/不误构靶子/功劳归材料体系）。
- **自查法**：默读一遍，读着像"销售总监在酒桌上讲明白了一件事"就过；读着像"AI 生成的行业通稿"就重写该段。

### Step 5 build 脚本
1. 复制最新范式脚本（当前为 `_build_youyou_kangjun.py`，含五层逻辑/合规边界最新写法）→ `_build_youyou_<slug>.py`。
2. 只改：`MD / IMG_DIR / OUT / SLUG`、标题卡三行（标签·主题 / 大字两句 / 定位句）、`<title>` 与隐藏 h1、`closing` 收口文案、`compliance` 合规边界（可说/避免按主题定制，结构收口句不变）。
3. 执行解释器：优先使用环境变量 `PYTHON_312` 指定的 Python 3.12；未配置时使用 `python`。确保该解释器已安装 PIL/Pillow（受管 3.13 可能无 PIL）。
4. 注释剥离必须 `re.sub(r"<!--[\s\S]*?-->", "", author)`，禁止逐行 startswith 过滤。

### Step 6 配图 + 图文联动升级 👤
1. 👤 用户提供海报（剪贴板粘贴 / 指定文件）。**不主动生成 AI 品牌海报**；封面一律用文章主视觉，不做 AI 封面。
2. **配图布局规划**：读全部海报（读图受限时按文件名语义 + IMA 知识卡推断），规划每张放哪个小节（hero→引导段后；对比图→01 误区；逻辑图→02；场景图→03 零售；系统图→05 结构能力；04 经销商可纯文字），报告布局后再动手。
3. **图文联动升级**（用户常说"基于海报内容对文章拓展补充、改写升级"）：把海报里的新信息织入正文（新层面/新卖点/场景句），使图文匹配；**图注优先用海报原话**。
4. **海报合规三条**：① 海报上的绝对化字样（"0滋生0霉变""永不"类）**不进正文**，转相对表述（"不给霉菌可乘之机/不易滋生"）；② 海报文字与系列口径/知识卡冲突时（如"零玄武岩成分" vs "玄武岩纤维织进板里"），**提醒用户核对、不擅改正文**；③ 与本文主题不符的海报不硬塞，预留到独立目录当下一篇主视觉（如静音门→`youyou-jingyin-geyin/`）。
5. 图片落盘后用 **PIL 像素特征校验映射**（整体明暗 / 左右半区亮度 / R-B 色调）核对「文件 ↔ 海报」顺序，再复制重命名进 `wechat-draft/<slug>/`：`00-xxx-hero.jpg` + 按小节命名。
6. 用户追加指定插入位置（红圈截图）→ 按圈定位置插图。
7. 无图时可先跑 `_gen_placeholders_<slug>.py` 生成标注占位图出预览（流程验证用），等真实图同名替换后删占位。
8. rebuild 自动压缩：RGBA→RGB 铺 #FDFBF7、宽≤1400px、JPEG q=82，目标 <250KB/张。

### Step 7 校验 + 预览交付（rebuild 后必跑，全 PASS 才交付）
1. 校验清单：标题三处一致含主题词 / 图片数=计划数且<250KB / Mike 开头 1 + 金句 1 / 5 编号小节 + 写在最后深色框 / 合规边界在写在最后**之后** / 固定页脚完整（4 条真实往期链接+作者卡+喜欢作者装饰+宇宙爱我）/ 残留 REPLACE·令牌=0 / 正文无 class·id·style。可写一段 python 校验脚本一次跑完。
2. **改稿循环惯例**：用户任何措辞微调 / 新点融入（本系列常有 10+ 轮）→ 改 md → **立即 rebuild + 重跑校验**，改一处 rebuild 一次，不让旧版滞留。
3. **预览交付**：用 present_files 打开输出 HTML（手机外壳预览）给用户看，附结构摘要与待办。

### Step 8 推草稿箱 👤
1. 👤 用户确认后执行（用户惯用短语"推到草稿箱/推送到草稿箱"）。
2. **推前检查**：确认 md 的所有修改都已 rebuild（防推旧版）；确认本次要推的是最终配图版而非占位版。
3. 命令（env 必须手动注入，scripts 目录 loadEnv 取不到 ../.env）：
   ```
   cd "<WORKBUDDY_HOME>/skills/wechat-publisher/scripts" && set -a && . <(sed 's/\r$//' ../.env) && set +a && npx tsx publish.ts "<WORKBUDDY_ROOT>/wechat-draft/<slug>.html" --cover "<WORKBUDDY_ROOT>/wechat-draft/<slug>/00-xxx-hero.jpg" --author "Mike"
   ```
   可选 `--digest "干净摘要"` 自定义摘要（默认自动抓取标题卡+开头，偏冗余）。
4. 成功标志：token OK → 全部正文图上传 mmbiz.qpic.cn → 封面素材库 OK → addDraft 成功，返回 draft media_id（记入当日日志）。
5. **重推=新建草稿**（不是更新原草稿）：同一篇多次推送会在草稿箱产生多版，提醒用户删掉旧版（尤其占位图版）。
6. 已知边界：个人未认证订阅号 freepublish 被封（只能草稿+手动群发）；IP 白名单 40164 时需用户在公众号后台加当前出口 IP（IP 随沙箱变化，非永久）；关注/赞赏须发布时在编辑器手动插原生组件。

### Step 9 收尾
- 当日日志追加：做了什么、media_id、遗留项（如海报口径待核对）。
- 👤 用户在草稿箱手动改摘要、删旧版占位草稿、发布时插原生组件。
